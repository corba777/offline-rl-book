# Offline RL: От теории к промышленной практике

<p class="byline">Created and maintained by <strong>Artem Zvyagintsev</strong></p>

<p class="disclaimer">Прикладные учебные заметки по offline deep RL — не авторитетный textbook. Материал суммирует алгоритмы, паттерны реализации и практические caveats; код — учебный каркас.</p>

Практическое руководство по офлайн обучению с подкреплением — для практиков, которые знают ML и хотят применять RL к реальным системам без живых экспериментов.

Каждая глава: **идея → формализация → код → ограничения**.
